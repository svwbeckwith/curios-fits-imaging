# CuRIOS FITS Imaging

Python tools and Jupyter notebooks for CuRIOS FITS image analysis, source detection, photometry, and plotting.

## Current status

This repository currently supports a Jupyter-based analysis workflow. The code is organized as a Python package so the same analysis layer can later support a command-line program or GUI.

## Repository layout

```text
fits_imaging/      Python package
notebooks/         Jupyter notebooks
tests/             Future tests
